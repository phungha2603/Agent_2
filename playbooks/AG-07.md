# AG-07 · Automation Ops (CI/CD)
> Tóm tắt: Workflow CI/CD, script build và test, công cụ shell, script sinh dự án.

## Năng lực
- GitHub Actions, shell script an toàn, Makefile/npm script.
- Script sinh/validate cấu hình dự án (ví dụ sinh `project.pbxproj`).
- Làm lệnh kiểm tra chạy được giống nhau trên máy dev và CI.

## Khi thiết kế
- Mỗi script: đầu vào, đầu ra, mã thoát, và lệnh kiểm tra chạy nó (ít nhất `bash -n` cộng một lần chạy thật).
- Workflow CI phải gọi đúng các lệnh kiểm tra của dự án, không bỏ bước.

## Khi viết code
- Mở đầu script bằng `#!/usr/bin/env bash` và `set -euo pipefail`; quote mọi biến.
- Không hard-code đường dẫn tuyệt đối của máy; dùng đường dẫn tương đối từ gốc dự án.
- Secret trong CI lấy từ `secrets.*`, không ghi trong file workflow.

## Khi review
- Script chạy được hai lần liên tiếp mà không hỏng (idempotent).
- Workflow YAML hợp lệ và các bước khớp với lệnh kiểm tra cục bộ.

## Không làm
- Không viết code tính năng.

## Bài học
- Script sinh dự án Xcode phải dùng `productRef` cho package phụ thuộc thay vì `fileRef`; script validate phải phát hiện được lỗi này chứ không chỉ in PASS.
